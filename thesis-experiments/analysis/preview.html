The Only Path That Matters? Preliminary figures and formal framework

Traceback sends a model only the root-to-node path of a branched chat. These figures compare that ancestor-only rule with sending the full tree and with an equal-budget sliding window, on 720 frozen scenarios answered by three models.

Preliminary. Leakage counts use the finished leak judge, which separates answers that used a sibling detail from answers that only mentioned or rejected it. Quality scores from the judge are still being collected and are not shown yet. Confidence intervals are Wilson 95% for rates and normal 95% for means. All counts use the first run of each scenario.

Formal framework

Why these results follow from the tree

A session is a rooted tree \(T=(V,E)\) of messages with root \(r\) and parent map \(p\). A logical clock \(\tau\) is injective and increases along every edge, and each message has a token weight \(w(v)>0\); for a set \(U\), \(w(U)=\sum_{u\in U} w(u)\). The question \(q\) is asked under the ask node \(a\) at a time \(\tau_q\) later than every message. The active path is \(\A=\{a,p(a),\dots,r\}\) and the sibling content is \(\Sib=V\setminus\A\). The rules are \(C_\anc=\A\) (root to node), \(C_\full=V\) (by time), and \(C_\win\), the longest run of newest messages whose weight stays within \(B=w(\A)\), never splitting a message.

Proposition 1 · containment and efficiency
\(C_\anc\subseteq C_\full\), and the token efficiency equals the siblings' share of the tree: \[E \;=\; 1-\frac{w(C_\anc)}{w(C_\full)} \;=\; \frac{w(\Sib)}{w(V)}.\]
Every element of \(\A\) is in \(V\), and \(w\) is a sum of positive terms, so it is monotone. Because \(V=\A\,\dot\cup\,\Sib\), \(w(V)=w(\A)+w(\Sib)\), which rearranges to the formula.
Proposition 2 · growth over a session
If a session grows one message at a time and every step re-sends its context, with \(w_{\min}\le w(v)\le w_{\max}\) and answered depth \(d_t\le D\), then \[\sum_{t=1}^{n} w(V_t)\;\ge\;w_{\min}\,\frac{n(n+1)}{2}=\Theta(n^2), \qquad \sum_{t=1}^{n} w(A_t)\;\le\;w_{\max}\,n\,(D+1)=O(nD).\]
\(|V_t|=t\) gives \(w(V_t)\ge t\,w_{\min}\); sum over \(t\). A root-to-node path at depth \(d_t\) has \(d_t+1\) nodes, so \(w(A_t)\le (d_t+1)\,w_{\max}\le (D+1)\,w_{\max}\).
Proposition 3 · ancestor-only cannot contain sibling facts
If every message containing a fact \(f\) lies in \(\Sib\) and \(q\) does not contain \(f\), then \(f\) does not occur in the ancestor-only prompt.
That prompt is the text of \(\A\) followed by \(q\). No message of \(\A\) contains \(f\), since all such messages lie in the disjoint set \(\Sib\), and \(q\) does not contain \(f\).
Proposition 4 · exposure times uptake
Let \(X_c(f)=\mathbf 1[f \text{ is in the prompt of } C_c]\), \(\pi_f\) the chance rate of mentioning \(f\) without seeing it, and \(u_c(f)\) the mention rate when exposed. Then \(X_c(f)\) is computable from the tree without a model, and for a sibling-only fact \[\Pr(M\mid c)-\Pr(M\mid \anc)\;=\;X_c(f)\,\bigl(u_c(f)-\pi_f\bigr).\]
Each rule is defined from \(T,\tau,w,a\) alone, so exposure is determined by them. By Proposition 3, \(\Pr(M\mid\anc)=\pi_f\). Under rule \(c\) the mention rate is \(\pi_f\) when \(X_c(f)=0\) and \(u_c(f)\) when \(X_c(f)=1\); subtract.
Proposition 5 · which messages the window keeps
A message \(m\) is in \(C_\win\) if and only if \(\displaystyle\sum_{u:\ \tau(u)\ge\tau(m)} w(u)\le B\). Consequently, whenever siblings exist, the root is never in the window, because that sum for \(r\) is \(w(V)=B+w(\Sib)>B\).
The window is the longest newest-first prefix whose weight stays within \(B\). Weights are positive, so prefix sums strictly increase, and \(m\) is included exactly when the prefix ending at \(m\), namely \(\{u:\tau(u)\ge\tau(m)\}\), fits.
Proposition 6 · one-for-one displacement
If \(\sigma=w(C_\win\cap\Sib)\) sibling tokens enter the window, then \(w(\A)-w(C_\win\cap\A)\ge\sigma\), and the active messages lost are the oldest ones. With late siblings, a fact in message \(m\) survives if and only if \(w(\Sib)\le w(\{u\in\A:\tau(u)<\tau(m)\})\).
\(w(C_\win\cap\A)+\sigma=w(C_\win)\le B=w(\A)\). If an active \(m\) is kept, any newer active \(m'\) has a smaller suffix sum and is kept too. For late siblings, the suffix from \(m\) is \(\Sib\) plus the active messages from \(m\) on; apply Proposition 5 with \(B=w(\A)\).
